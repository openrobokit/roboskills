# RoboTwin 2.0

RoboTwin 2.0 is a scalable data generator and benchmark for bimanual manipulation with strong domain randomization,
in SAPIEN. Here `launch.make(task, seed, information, out)` runs its task envs with the aloha-agilex robot's two arms
behind the shared `Robot` contract, scored by RoboTwin's own success checks. See [SKILL.md](SKILL.md).
