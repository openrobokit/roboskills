# RoboCasa365

RoboCasa365 is a large-scale simulation framework of kitchen tasks for training and benchmarking generalist robots,
built on robosuite and MuJoCo. Here `launch.make(task, seed, out)` runs five of its kitchen tasks with RoboCasa's
PandaOmron mobile manipulator behind the shared `Robot` contract, including its base. See [SKILL.md](SKILL.md).
