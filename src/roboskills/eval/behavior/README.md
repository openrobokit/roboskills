# BEHAVIOR-1K

BEHAVIOR-1K is a benchmark of 1,000 everyday household activities, simulated in OmniGibson on Isaac Sim. Here
`launch.make(task, seed, out, gpu)` runs a 2026 BEHAVIOR Challenge task instance with the R1Pro mobile manipulator in
the official image, behind the shared `Robot` contract with a mobile base. See [SKILL.md](SKILL.md).
