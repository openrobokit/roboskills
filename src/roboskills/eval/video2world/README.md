# Video2World

Video2World benchmarks coding agents that turn embodied videos into interactive simulations, scoring the
reconstructed worlds for geometric fidelity, dynamic fidelity and functional correctness. Here [SKILL.md](SKILL.md) is
the protocol for matched evaluations of frozen reconstruction submissions with the official scores and synchronized
comparison videos, and `media.py` probes, transcodes and embeds those videos.
