# HumanoidArena

HumanoidArena benchmarks egocentric hierarchical whole-body learning for humanoid robots. Here
`launch.make(task, seed, out, gpu)` runs an official test episode with the Unitree G1 and Dex3 hands under the frozen
GEAR-SONIC whole-body controller on Isaac Sim 6.1, behind the shared `Robot` contract with walking and squatting.
See [SKILL.md](SKILL.md).
